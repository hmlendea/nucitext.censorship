# Repository structure

## Source tree layout

```
nucitext.censorship/
├── ARCHITECTURE.md
├── CONTRIBUTING.md
├── LICENSE
├── NuciText.Censorship.slnx
├── PRIVACY.md
├── README.md
├── SECURITY.md
├── .github/
│   ├── FUNDING.yml
│   └── workflows/
│       └── dotnet.yml
└── NuciText.Censorship/
    ├── ITextCensor.cs
    └── NuciText.Censorship.csproj
```

## Module organisation

| Path | Type | Description |
|------|------|-------------|
| `NuciText.Censorship/ITextCensor.cs` | Source | The sole public interface defining the censorship contract. |
| `NuciText.Censorship/NuciText.Censorship.csproj` | Project | The NuGet package project file. Declares target framework `net10.0`, package metadata, and build properties. |
| `NuciText.Censorship.slnx` | Solution | Solution file referencing the single project. |
| `.github/workflows/dotnet.yml` | CI/CD | GitHub Actions workflow: restore, build, and test on every push and pull request to `master`. |
| `ARCHITECTURE.md` | Documentation | Root architecture document describing purpose, components, dependency direction, and extension points. |
| `README.md` | Documentation | Project overview, usage example, installation instructions, and development guide. |
| `CONTRIBUTING.md` | Documentation | Contribution guidelines, code style, testing, and PR process. |
| `SECURITY.md` | Documentation | Security policy, supported versions, and vulnerability reporting. |
| `PRIVACY.md` | Documentation | Privacy policy describing data handling (none). |
| `LICENSE` | Legal | GNU General Public License v3.0 or later. |

## Build artefacts

The `bin/` and `obj/` directories are generated by the .NET SDK during build and are excluded from version control via `.gitignore`. They are not part of the repository source.

## Absence of tests

The repository contains no test project. The package is interface-only; verification is delegated to consumers and implementers of `ITextCensorship`. See [Testing](./testing.md) for details.
